Demo trong 3 bước Chọn địa điểm → Giả lập vị trí → Xem kết quả
  1. Chọn một địa điểm đang hoạt động và bấm “Dùng tọa độ này để giả lập”.
  2. Bấm “Kiểm tra vị trí giả lập” để nhận kết quả từ hệ thống.
  3. Thử tọa độ ở xa để thấy trạng thái ngoài phạm vi, hoặc bật định vị để dùng GPS thật.

GPS thật cần HTTPS hoặc localhost và quyền vị trí của trình duyệt. Nếu chưa có địa điểm, hãy tạo POI bằng API theo README rồi tải lại danh sách.
